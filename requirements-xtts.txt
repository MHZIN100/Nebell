# Dependencias SO da voz XTTS -- opcional e PESADA (~2 GB).
#
# A XTTS e a voz offline de mais alta qualidade do NEBELL, mas exige o
# PyTorch inteiro e um modelo de ~1.8 GB, e trava em maquinas com pouca
# memoria (8 GB de RAM nao aguentam). Por isso ela NAO entra na instalacao
# normal e vem desligada por padrao (USAR_XTTS = False no nebell.py).
#
# So instale isto se tiver uma maquina forte (16 GB+ de RAM) e quiser a
# XTTS. Sem isto, o NEBELL usa a voz hibrida Microsoft + Kokoro, que ja e
# excelente e leve.
#
# Como instalar (com o ambiente do NEBELL):
#     .venv\Scripts\python.exe -m pip install -r requirements-xtts.txt
#   e depois, para baixar o modelo:
#     .venv\Scripts\python.exe instalar.py --com-xtts
#
# Por fim, ligue USAR_XTTS = True no topo do nebell.py.

# O coqui-tts NAO puxa o PyTorch sozinho, entao o torch e o torchaudio
# vem explicitos (versao CPU; a placa de video fica com o Ollama). O
# torchcodec e exigido pelo PyTorch 2.9+ para ler e gravar audio. O six
# e uma dependencia antiga que o coqui ainda espera encontrar pronta.
torch
torchaudio
torchcodec
six
coqui-tts
